# 安装方法

**前置要求：**
在使用本插件前，请确保您的 Collapse Launcher 版本为 `1.83.14` 或更高版本。

## 安装步骤

1. **下载插件**
   前往 [插件列表](/plugins) 下载最新的插件压缩包（
   `.zip` 文件）。

   ![Release Download Page](/installation/image.png)

2. **进入插件管理**
   打开启动器，进入 **设置 (Settings)** 页面，向下滚动找到并点击 `打开插件管理菜单`。

   ![Settings Menu](/installation/img_2.png)

3. **添加并应用**
   在弹出的窗口中，点击 `点击添加 .zip 或 manifest.json` 按钮，选择刚刚下载的 `.zip` 文件。

   完成添加后，**重启启动器**即可生效。

   ![Add Plugin Dialog](/installation/img_1.png)
