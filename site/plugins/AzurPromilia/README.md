# Azur Promilia

This plugin adds Azur Promilia support to Collapse Launcher on Windows x64. Use it to download, update, and launch the game.

Download the ZIP from this page, add it in Collapse Launcher's Plugin Management menu, and restart the launcher. See the [source repository](https://github.com/misaka10843/Hi3Helper.Plugin.Azurpromilia) for details and issue reports.
